# Материалы занятий

Личная библиотека лекций по лингвистике: краткие конспекты, полные транскрипции, задания и дополнительные материалы. Клиентское приложение (SPA) со статической структурой без сборки, данные — Supabase.

## Дизайн-система Claude Dark

Интерфейс оформлен в строгом стиле тёмной темы Claude (Anthropic):

- **Цветовая палитра:** фон страницы `#191919`, карточки `#202020` / `#212121`, границы `#2e2e2e` / `#333333`, акцентный фирменный терракотовый `#d97757` (ховер `#e28a6c`);
- **Типографика:** Literata для книжных заголовков и чтения, Inter для интерфейса и навигации;
- **Плавные бесшовные переходы (App-like SPA):** мгновенная навигация без перезагрузки браузера, стабильный сайдбар и верхняя панель без мерцаний и скачков;
- **Кэширование данных:** каталог сохраняется в сессии для моментального открытия страниц (0 мс);
- **Читаемость:** контрастный текст `#ffffff` для заголовков, `#e2e2e2` для текста лекций, чёткие плашки предметов;
- **Симметричный векторный логотип:** чистый SVG-фавикон во вкладках браузера.

## Структура проекта

```
index.html          Главная страница (библиотека занятий)
subjects.html       Предметы
saved.html          Избранное
lecture.html        Читалка лекций (конспект, транскрипция, задания, доп. материалы)
privacy.html        О сайте
assets/
  css/              Стили (site.css, formatting.css, extras.css, fonts.css)
  fonts/            Локальные шрифты Literata и Inter (SIL OFL 1.1)
  js/               SPA-маршрутизатор, клиент Supabase, поиск, доступ
  favicon.svg       Векторная иконка Claude (терракотовая искра)
admin/              Панель управления владельца (расписание, статистика, редактор)
```

## Локальный запуск

```bash
# Node.js
npx serve .

# или Python
python -m http.server 4173
```

Параметры подключения к Supabase — в `assets/js/config.js`.
