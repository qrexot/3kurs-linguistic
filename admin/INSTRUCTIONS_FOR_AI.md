# РУКОВОДСТВО ПО ОФОРМЛЕНИЮ УЧЕБНЫХ МАТЕРИАЛОВ ДЛЯ НЕЙРОСЕТИ (CLAUDE DARK STYLE)

> Данный документ предназначен для добавления в системный промпт, проект (Claude Project Knowledge), базу знаний Custom GPT или в контекст любого ИИ (Claude, ChatGPT, DeepSeek, Qwen) для автоматической разметки и структурирования студенческих лекций.

---

## 1. Главные принципы
1. **Точность и достоверность:** Категорически запрещено выдумывать факты, термины, домашние задания, сроки сдачи или требования к экзамену, которых не было в исходном материале.
2. **Язык:** Основной язык изложения — русский. Все иностранные термины, латинские формулы, примеры на других языках и цитаты сохраняются в оригинальном написании.
3. **Чистота разметки:** Возвращайте **только** готовую Markdown-разметку. Не добавляйте приветствий («Вот ваш текст...»), заключений и внешних обрамляющих тройных кавычек (\`\`\`markdown ... \`\`\`).
4. **Запрещённые элементы:** Не используйте HTML-теги (\`<div>\`, \`<span>\`, \`<br>\`), стандартные Markdown-картинки (\`![]()\`) и LaTeX-разметку (\`$...$\`, \`$$...$$\`). Фотографии к лекции добавляются отдельно через интерфейс сайта.

---

## 2. Иерархия заголовков и разделов
- `## Заголовок раздела` — основной раздел лекции. На сайте заголовкам `##` автоматически присваивается порядковый номер (01, 02, 03...).
- `### Подраздел` — логическая часть внутри раздела.
- `#### Пункт` — мелкое подразделение или аспект темы.
- `---` — горизонтальный разделитель между крупными тематическими блоками.

---

## 3. Выделение текста в строке (Inline-стили)
- `**жирный текст**` — ключевые понятия, определения, имена авторов.
- `*курсив*` — языковые примеры, цитаты, авторские ремарки.
- `==маркер==` — критически важная фраза (подсвечивается фирменным тёплым цветом).
- `++подчёркивание++` — грамматические разборы, орфограммы, морфемы.
- `~~зачёркивание~~` — ошибочные или устаревшие варианты.
- `x^2^` и `H~2~O` — верхние и нижние индексы (степени, формулы, сноски).
- `` `термин или код` `` — инлайн-код, символы транскрипции, программные команды.
- `{{Ctrl+C}}` — клавиатурные сочетания и горячие клавиши.
- `{tag:Лингвистика}` — компактный бейдж-тег для категорий.
- `[Текст ссылки](https://адрес)` — внешняя ссылка на источник.

## 4. Списки, чек-листы и словари
### Простой список
```markdown
- Первый тезис
- Второй тезис
  - Вложенный тезис (отступ ровно 2 пробела)
```

### Нумерованный список шагов
```markdown
1. Первый этап
2. Второй этап
3. Заключительный этап
```

### Чек-лист заданий или плана
```markdown
- [ ] Пункт, который предстоит выполнить к следующему занятию
- [x] Вопрос, который уже был разобран на лекции
```

### Словарь понятий (Definition List)
```markdown
Термин
: Чёткое научное определение понятия в одну или две строки.

Другой термин
: Определение второго понятия.
```

## 5. Таблицы
Используйте стандартный синтаксис таблиц с поддержкой выравнивания. Если в тексте таблицы нужен символ вертикальной черты, экранируйте его: `\|`.
```markdown
| Понятие | Характеристика | Пример |
| :--- | :---: | ---: |
| Слева (текст) | По центру | Справа (число) |
| Фонема | Абстрактная единица | /b/, /p/ |
```

---

## 6. Смысловые блоки (Callouts)
Смысловой блок начинается отдельной строкой `:::тип` (или `:::тип Заголовок блока`) и обязательно закрывается отдельной строкой `:::`.

| Тип блока | Назначение | Рекомендация к использованию |
| :--- | :--- | :--- |
| `:::definition` | Определение | Для строгих формулировок терминов и понятий |
| `:::important` | Важно | Главная мысль раздела, которую нельзя упустить |
| `:::remember` | Запомнить | Формулировки, правила или даты, требующие заучивания |
| `:::example` | Пример | Наглядный пример из учебного материала или текста |
| `:::rule` | Правило | Грамматический закон, логическое правило, аксиома |
| `:::warning` | Обратите внимание | Предостережение, тонкий нюанс или исключение |
| `:::tip` | Подсказка | Практический совет, лайфхак по запоминанию |
| `:::mistake` | Частая ошибка | Типичное заблуждение студентов и его опровержение |
| `:::question` | К экзамену | Экзаменационный или проверочный вопрос |
| `:::answer` | Ответ | Ответ на поставленный вопрос |
| `:::task` | Задание | Домашнее задание, упражнения, подготовка к паре |
| `:::summary` | Краткий итог | Выводы по разделу или лекции в 2–4 пунктах |
| `:::translation` | Перевод | Исходная фраза на иностранном языке и её перевод |
| `:::pronunciation` | Произношение | Транскрипция, ударение, фонетические особенности |
| `:::dialogue` | Диалог | Реплики беседы, спор на семинаре |
| `:::steps` | По шагам | Последовательность действий, алгоритм решения |
| `:::timeline` | Хронология | Историческая последовательность событий по годам |
| `:::terms` | Термины | Подборка ключевых терминов темы |
| `:::formula` | Формула | Текстовая запись формулы без LaTeX (напр. \`A + B = C\`) |
| `:::verse` | Текст для разбора | Стихи или цитаты с сохранением переноса строк |
| `:::note` | Заметка | Короткая поясняющая мысль на полях |
| `:::source` | Источник | Библиографическая ссылка или цитируемый труд |

## 7. Интерактивные компоненты

### Раскрывающийся спойлер (Details)
Используйте для ответов на самопроверку, объемных доказательств или вспомогательных исторических справок:
```markdown
:::details Нажмите, чтобы увидеть разбор
Здесь находится скрытый текст с подробным решением или ответом.
:::
```

### Сравнение в 2 или 3 колонки (Columns)
Колонки разделяются символами `|||` на отдельной строке:
```markdown
:::columns Сравнение двух подходов
**Синхрония**
Изучение языка в данный момент времени как готовой системы.
|||
**Диахрония**
Изучение исторического развития языка во времени.
:::
```

### Блоки кода (Fenced Code)
```text
```python
# код с сохранением отступов и символов
def analyze_phoneme(sound):
    return sound.is_voiced()
```
```

### Сноски
```markdown
Понятие фонемы было сформулировано Бодуэном де Куртенэ[^1].

[^1]: Иван Александрович Бодуэн де Куртенэ (1845–1929) — выдающийся польский и российский лингвист.
```

## 8. Режимы обработки текста
- **«Лекция»:** глубокая переработка стенограммы или черновика в структурированный конспект. Выделяйте главные темы заголовками `##`, важные мысли блоками `:::important`, термины блоками `:::definition`, практические примеры блоками `:::example` и итоги `:::summary`.
- **«Полная транскрипция»:** дословное сохранение речи участников в хронологическом порядке. Оформляйте диалоги через `:::dialogue` или маркированные реплики, сохраняя все детали без сокращений.
- **«Задание»:** краткая выжимка только того, что преподаватель явно задал к следующей паре. Оформляйте через `:::task` с чек-листом `- [ ]`.
